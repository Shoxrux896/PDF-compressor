# Руководство по разработке

Цель: быстро понять, где и как менять поведение сжатия/конвертации, добавлять тесты и проверять изменения.

1) Где менять логику конвертации
- `src/utils/imgToPdf.ts` — основной файл. Основные точки изменения:
  - Сжатие: вызов `imageCompression(file, { maxSizeMB: ..., useWebWorker: true })` — замените параметры, добавьте `maxWidthOrHeight` или используйте другой алгоритм.
  - Параллельность: сейчас итерация по `items` последовательная. Для параллельного сжатия используйте батчи `Promise.all` с ограничением concurrency (например, p-limit).
  - Page sizing: расширьте `PdfOptions` (например, `dpi`, `customWidth`, `customHeight`) и измените расчёт `pageWidth/pageHeight`.
  - Rotation: текущая логика рассчитана на 0/90/180/270. Для произвольных углов потребуется более сложная матрица трансформации.

2) Тестирование изменений
- В проекте нет юнит-тестов по умолчанию. Для добавления тестов:
  - Установите Jest/ Vitest и напишите тесты для `imageUtils` и `imgToPdf`.
  - Для `imgToPdf` можно мокать `browser-image-compression` и `pdf-lib` чтобы проверять, что страницы добавляются в правильном порядке и с нужными размерами.

3) UI и компоненты
- `src/pages/Home.tsx` — центральная точка интеграции. Изменение подписи кнопки/поведения конвертации происходит тут.
- `SortableImageGrid.tsx` использует `@dnd-kit`. Если нужно добавить drag-handle или иконки — измените `SortableItem`.

4) Производительность и память
- Сжатие больших изображений в браузере может потреблять много памяти. Ограничьте максимальный размер файла на уровне UI или перед сжатием уменьшайте resolution (`createThumbnail` может служить примером).

5) Советы по отладке
- Используйте `console.time`/`console.timeEnd` вокруг тяжёлых участков (`imageCompression`, `pdfDoc.save()`) для измерения.
- Тестируйте на мобильных устройствах и старых браузерах — `browser-image-compression` может вести себя иначе.

6) Примеры изменений
- Пример: добавить параметр `dpi` — обновите `PdfOptions`, измените масштаб при вставке изображения перед `page.drawImage`.
