# Карта файлов и краткое описание

Корневая структура (важные файлы/папки):

- `index.html` / `public/` — стандартные статические файлы для Vite.
- `package.json` — скрипты и зависимости.

src/
- `src/main.tsx` — точка входа приложения, роутер и глобальный CSS подключены здесь.
- `src/App.tsx` — маршрутизация (ленивая загрузка `Home` и `Admin`).
- `src/firebase.ts` — инициализация Firebase SDK (Firestore). Рекомендуется вынести секреты в env.

components/
- `FileUploader.tsx` — UI выборки файлов, отдаёт массив `File` в `onSelect`.
- `SortableImageGrid.tsx` — реализует drag-and-drop с помощью `@dnd-kit`; хранит превью, rotation, удаление, reorder.
- `Preview.tsx` — заглушка/простая область превью (в текущей версии минимальна).
- `ThemeToggle.tsx`, `LanguageSwitch.tsx` — UI для темы и языка.

pages/
- `Home.tsx` — основной экран: управление состоянием `items`, опциями PDF, прогрессом и вызов `imgToPdf`.
- `Admin.tsx` — лениво подгружаемая страница (не детализирована в документации, открыть файл для деталей).

utils/
- `imageUtils.ts` — `createThumbnail` (canvas → blob → URL), используется при загрузке файлов.
- `imgToPdf.ts` — основная логика: сжатие + встраивание изображений в PDF (`pdf-lib`). Экспортирует `imgToPdf` и тип `PdfOptions`.
- `analytics.ts` — функции логирования событий (используются в `Home`).

i18n/
- `translations.ts` — словарь переводов (`en`, `ru`, `uz`). Текущая локализация используется в `Home` и компонентах.

Другие: `main.css` — глобальные стили; `vite.config.ts`, `tsconfig*.json` — конфиги сборки/TS.
