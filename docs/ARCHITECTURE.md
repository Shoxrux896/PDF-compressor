# Архитектура проекта

Цель: объяснить, как данные проходят от выбора изображений в UI до результата — PDF-файла.

1) Основной поток
- Пользователь выбирает изображения с помощью `FileUploader` или добавляет их повторно через интерфейс.
- `Home.tsx` создаёт для каждого файла объект с `id`, `file`, `preview` (URL миниатюры) и `rotation`.
- `SortableImageGrid` предоставляет UI для изменения порядка, удаления и поворота элементов. Порядок — важен для последовательности страниц в итоговом PDF.
- При нажатии `Convert` `Home` вызывает `imgToPdf(items, quality, options, onProgress)`.

2) Конвертация (utils/imgToPdf.ts)
- Для каждого файла выполняется сжатие через `browser-image-compression` (параметр `maxSizeMB` основан на `quality`).
- Сжатый blob встраивается в `pdf-lib` как JPG/PNG.
- Для страницы вычисляются размеры (A4/Letter/Auto). Для `auto` размер страницы соответствует изображению (с учётом поворота).
- Изображение центрируется и масштабируется так, чтобы поместиться с учётом полей.
- Повороты реализованы как угол кратный 90°, с корректировкой координат при `drawImage`.

3) Вспомогательные модули
- `imageUtils.createThumbnail` — создаёт canvas-превью, возвращает URL для `img.src` в превью.
- `analytics` — простое логирование событий (визит, загрузка, конвертация).
- `firebase.ts` — инициализация Firebase SDK (Firestore). В текущем коде Firestore используется для аналитики/логов, но не для хранения файлов.

4) UI
- Ленивые страницы: `App.tsx` загружает `Home` и `Admin` через `React.lazy`.
- Тема и язык переключаются через `ThemeToggle` и `LanguageSwitch`; строки локализации в `src/i18n/translations.ts`.

5) Расширяемость
- Хранение: добавить сохранение результатов в Firebase Storage — расширить `Home` или создать отдельный `storage` util.
- Форматы: добавить опцию DPI или явной ширины/высоты страницы в `PdfOptions`.
- Параллелизм: для ускорения можно сжимать изображения параллельно (Promise.all) с ограничением concurrency.

---

Примечание: при модификации логики генерации PDF сначала запустите `Home` в dev режиме и протестируйте на 5-10 изображениях, чтобы проверить стабильность памяти и время выполнения.
